    使用说明

    了解照片如何归档、同步，以及如何安全维护。

    1. 1

      上传照片

      选择设备与原始文件，上传到照片网关。

    2. 2

      检查重复

      根据文件信息预检，疑似重复由你确认。

    3. 3

      按拍摄月份归档

      按照拍摄时间整理归档，原始文件不变。

    4. 4

      自动同步到 NAS

      归档完成且条件满足时，自动同步至 NAS。

    5. 5

      可选的本地历史清理

      需要人工执行命令，删除已同步且达到保留期的本机旧副本。

    i原始照片不会被压缩或修改；本地清理仅删除确认已同步且达到保留期的本机副本。NAS 上的正式副本不受影响。

    常见维护命令

    以下为常用的维护命令示例，请在终端中执行。

    共 9 项 · 上下滚动查看全部命令

    检查配置

    检查当前配置是否正确。

    python -m photo_gateway check --config <配置>

    生成一致性数据库备份

    备份网关数据库，用于恢复与排查。

    python -m photo_gateway db-backup --config <配置>

    生成登录密码哈希

    生成加密串后写入配置；不要公开展示结果。

    python -m photo_gateway hash-password

    启动网页与后台服务

    在正确运行环境中启动；Docker 部署请在容器内执行。

    python -m photo_gateway serve --config <配置>

    清理过期临时文件与缓存

    只处理过期临时文件和预览缓存。

    python -m photo_gateway maintenance --config <配置>

    核对本地缺失文件

    标记本地已丢失的照片记录，不删除照片。

    python -m photo_gateway maintenance --config <配置> --scan-missing

    补读旧照片 EXIF

    为旧照片补全拍摄信息，可重复执行。

    python -m photo_gateway backfill-exif --config <配置>

    对齐文件时间

    把旧文件的时间对齐到拍摄时间。

    python -m photo_gateway align-mtime --config <配置>

    预览可本地清理的月份（只查看）

    列出已同步且达到保留期的月份，供确认；不会删除文件。

    python -m photo_gateway cleanup --config <配置>
    查看完整命令说明：在终端运行 python -m photo_gateway --help，或参考项目 README 文档。
    !

    本地清理需要谨慎

    只有已成功同步到 NAS 且超过保留期的月份才符合条件。先运行左侧预览命令核对；实际删除必须由维护人员在终端明确执行。

    会删除本机历史照片副本

    python -m photo_gateway cleanup --config <配置> --apply --yes

    该命令会删除已同步且达到保留期的本机旧副本。请在确认无误后由维护人员执行。

    i归档 = 按拍摄月份整理；同步 = 单向复制至 NAS；清理 = 删除已安全同步的本机旧副本。
    常见问题

    原始照片会被修改吗？

    不会。系统保留上传的原始文件；网页缩略图是独立缓存，可按需重建。

    清理会删除 NAS 上的照片吗？

    不会。清理命令只删除本机已确认同步且达到保留期的副本。
