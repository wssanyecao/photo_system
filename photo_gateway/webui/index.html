    说明
    它是怎么工作的上传 → 去重 → 归档 → 同步 → 本地清理
    1. 上传照片从手机 / 电脑浏览器或 App 把照片传到这台设备；系统会先“检测是否上传过”，再接收文件并写入临时区。
    2. 自动归档（入库）后台把“已上传完成”的照片读取拍摄时间（没有拍摄信息的按文件时间），归档到 Photos/年份/年月 目录；整个过程不改动照片原文件，只是整理存放。
    3. 重复识别同一张照片再次上传会被识别出来（按文件内容指纹），提示您“跳过”或“重传”；一张照片在库中只保留一份记录。
    4. 网页预览与缓存照片页展示的是自动生成的小尺寸预览图，浏览时临时存放在缓存目录，超过保留时间（默认 90 天）会自动清理，需要时会重新生成。
    5. 同步到 NAS（正式库）等没有新的上传在等待处理后，系统把已归档照片单向复制到 NAS，并保留拍摄时间；NAS 上的照片库可由 Immich 等相册软件读取（本设备只做中转与短期保存）。同步按顺序检查几个条件，都满足才执行（见“照片同步状态”页）。
    6. 本地历史清理已经成功同步到 NAS 并超过本地保留期（默认 90 天）的历史月份，可以删除本机副本释放空间。“照片同步状态”页只提示哪些月份可清理，不会自动删除。
    维护命令在设备上用终端执行；涉及删除的操作已用红色标出，请先阅读“注意”
    命令作用适合什么时候用注意
    python -m photo_gateway check --config <配置>检查配置文件是否正确每次修改配置后、重启前错误时会给出原因
    python -m photo_gateway hash-password生成登录密码的加密串开启登录保护前结果写进配置的密码字段
    python -m photo_gateway serve --config <配置>启动网页与后台处理服务日常运行修改配置后需重启生效
    python -m photo_gateway maintenance --config <配置>手动清理过期临时文件与预览缓存磁盘紧张时，或不想等每日自动清理只删过期缓存，安全
    python -m photo_gateway maintenance --config <配置> --scan-missing核对：标记本地文件已丢失的照片外部误删文件后，让照片页不再显示缺失项只做标记，不删任何文件
    python -m photo_gateway backfill-exif --config <配置>为旧照片补读拍摄信息老库升级后想补全归档信息可重复执行
    python -m photo_gateway align-mtime --config <配置>把旧文件的时间对齐到拍摄时间时间线错乱时修复可重复执行
    python -m photo_gateway cleanup --config <配置>预览可本地清理的月份（不删除）想看看哪些历史月份已可清理安全预览
    python -m photo_gateway cleanup --config <配置> --apply --yes真正删除本机已同步的历史月份确认 NAS 上已有备份后再执行会永久删除本机该月照片副本，需两个参数同时给出才执行；删除会记录日志
    命令统一需要 Python 3.12 环境与合法配置；具体每个参数的说明见仓库 README「运维命令行」章节。上面约简写法中 <配置> 是配置文件的路径。
